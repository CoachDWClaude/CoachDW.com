# Progress graph

`index.html` is the module preview. It plugs in with `SFLProgress.mount(element, data, options)`, and `SFLProgress.fromApp(D)` converts the app's saved data.

The live app still has its simpler graph. This module has not been plugged in yet.

The module's What Changed panel already reads sleep, feel and rest days, so BodyStats can feed it more.
